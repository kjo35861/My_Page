# 짧은 확인 방법

1. **어디로 가나요**: 결과물 주소로 접속해 첫 화면(공개 소개 페이지)을 맨 아래까지 스크롤하면 "비공개 자리" 섹션이 보입니다.
2. **세 단계 안에 무엇을 하나요**: ① "패스키 등록(가입)" 탭에서 아이디·표시 이름·패스키 이름을 입력하고 등록 버튼을 누른다 → ② 브라우저가 띄우는 패스키 생성 창에서 지문/얼굴/보안키 등으로 확인한다 → ③ 등록이 끝나면 자동으로 로그인되어 비공개 항목이 보인다.
3. **무엇이 보이면 통과인가요**: 로그인 상태 문구("~님 — 패스키로 로그인된 상태입니다")와 함께 비공개 항목 목록, 등록된 패스키 목록이 화면에 나타나면 통과입니다.
4. **안 될 때는 무엇이 보이나요**: 로그인/등록 실패 시 폼 아래 빨간색 문구로 실패 사유(예: "존재하지 않는 계정입니다.", "로그인 요청이 만료되었거나 이미 사용된 질문입니다.")가 표시됩니다.

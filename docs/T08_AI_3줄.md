# AI와 내 판단 (T08)

- **AI에게 맡긴 일**: WebAuthn 등록/인증 옵션 생성·서명 검증 라이브러리(`@simplewebauthn/server`, `@simplewebauthn/browser`)의 정확한 함수 시그니처 확인과 Express 라우터·Supabase 스키마 기본 뼈대 작성.
- **내가 직접 판단한 일**: 비공개 자료를 조회할 때 `userId`를 클라이언트 입력이 아니라 항상 세션 쿠키에서만 읽도록 정한 것, 이미 있는 계정에는 로그인한 상태에서만 패스키를 추가할 수 있게 막은 것, 패스키를 전부 지웠을 때 계정이 잠기는 것을 허용하기로 한 것.
- **AI 제안을 따르지 않은 일**: 없음 — 제안된 보안 경계와 구조를 검토한 뒤 대체로 그대로 받아들였고, 크게 반대한 지점은 없었다.
